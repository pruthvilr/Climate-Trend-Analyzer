# 🌍 Climate Trend Analyzer

Data Science based climate data dashboard built with Streamlit.

## Features
- Long-term temperature trend visualization
- Seasonal decomposition
- Climate anomaly detection
- Interactive charts using Plotly

## Tech Stack
- Python
- Pandas
- Streamlit
- Plotly
- Statsmodels

## Run Locally
pip install -r requirements.txt

python data_gen.py

streamlit run app.py
